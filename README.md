# Online Event Booking and Management System

## Project Overview

The **Online Event Booking and Management System** is a full-stack web application that enables users to discover events, book tickets online, and manage their bookings. It also provides organizers with tools to create and manage events, while administrators can monitor users and events through an admin dashboard.

The project aims to replace manual event registration with a secure, user-friendly, and efficient online platform.

---

## Features

### User Module

* User Registration and Login
* Browse Upcoming Events
* View Event Details
* Book Event Tickets
* Booking Confirmation
* View Booking History

### Organizer Module

* Organizer Login
* Add New Events

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/online-event-booking-system.git
```

### 2. Open the Project

```bash
cd online-event-booking-system
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the backend folder.

Example:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

### 5. Start the Backend Server

```bash
node server.js
```

or

```bash
npm start
```

Server runs at:

```
http://localhost:5000
```

### 6. Run the Frontend

Open `index.html` in your browser or use Live Server in Visual Studio Code.
